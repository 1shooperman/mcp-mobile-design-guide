# Security Policy

## Supported Versions

This project is under active development on `main`. Security fixes are only
applied to the latest commit on `main`.

## Reporting a Vulnerability

Report security vulnerabilities by [opening a bug report](../../issues/new?template=bug_report.md).
Include as much detail as possible: affected component, reproduction steps,
and potential impact.

Do not include secrets, credentials, or sensitive data in the issue.
